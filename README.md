# Promptoteca

Site de estudo de engenharia de prompts, com cards, checklist PACREF, uma visualização do mecanismo da repetição de prompt e exercícios de memorização.

## Como usar

Abra o site publicado no GitHub Pages ou baixe o arquivo `index.html` e abra no navegador. Não há dependências externas.

## Conteúdo e fontes

- Cards 01 a 15: síntese educativa baseada em *Engenharia de Prompts na Prática*, de Edney "InterNey" Souza. Exemplos adaptados para estudo.
- Cards de Pesquisa e novas Técnicas: estudos listados na seção de referências do próprio site, consultados em 15 out. 2026. O principal é Leviathan, Kalman e Matias, *Prompt repetition improves non-reasoning LLMs*, arXiv:2512.14982 (preprint).

## Avisos

- Técnicas de revisão ajudam, mas não garantem a correção das respostas de uma IA.
- Os resultados da pesquisa descrevem os modelos e as tarefas testados; teste no seu contexto antes de adotar.
- Não cole dados pessoais ou sigilosos em ferramentas de IA.
